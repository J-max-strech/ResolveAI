Sobre o projeto

Conhecimento institucional, com clareza.

O ResolveAI é uma proposta de interface para facilitar a consulta a regulamentos e documentos institucionais por meio de perguntas em linguagem natural.

Não há conexão com serviços de IA nem com o portal do IFTO. Respostas, fontes e documentos exibidos são fictícios e servem apenas para demonstrar a experiência. Consulte os canais e documentos oficiais para obter orientações válidas.
